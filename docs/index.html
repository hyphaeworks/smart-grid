SmartGrid

Auto-rebalancing CSS Grid to avoid orphan items.

Usage

<link rel="stylesheet" href="smart-grid.css">
<script type="module" src="smart-grid.js"></script>

<smart-grid columns="3">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</smart-grid>

Include the stylesheet and the script, then use <smart-grid> with a columns attribute.
